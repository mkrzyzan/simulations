🎯 Rubber Sheet Simulation

Interactive physics simulation using Newtonian mechanics

📌 How to Use

Click anywhere on the canvas to create a new rubber sheet network.

  • Each click generates a 10×10 grid of interconnected mass points
  • Watch as forces between points create wave-like motion
  • The simulation uses discrete Newtonian physics calculations
  • Gravity and spring forces create realistic behavior
